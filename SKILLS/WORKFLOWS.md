# WORKFLOWS

Ce fichier décrit comment les Skills collaborent entre eux.

## Création d'un épisode

1. Ray Orchestrator reçoit la demande.
2. Ray Director vérifie la cohérence.
3. Ray Continuity contrôle la continuité.
4. Ray Memory retrouve les informations existantes.
5. Ray Writer rédige.
6. Ray Prompt Engineer génère les prompts.
7. Ray Vision valide les images.
8. Ray Social Media prépare la publication.

Chaque Skill intervient uniquement dans son domaine.
